# Risk-to-Control Mapping

|---|---|---|---|---|
| Named owner | Required | Required | Required | Required |
| Evaluation | Basic | Standard | Enhanced | Enhanced |
| Human review | As needed | Required for material output | Strong | Mandatory |
| Tool approval | If write action | Required | Strict | Strict |
| Monitoring | Periodic | Regular | Continuous/regular | Continuous |
| Incident plan | Basic | Required | Required | Required |
| Re-review | Annual | Semiannual | Quarterly | Frequent |
