# Release Gates

Before production:

- [ ] Use case registered
- [ ] Risk level approved
- [ ] Data/privacy review complete
- [ ] Model approved
- [ ] Prompt/version documented
- [ ] Tools reviewed
- [ ] Evaluation threshold met
- [ ] High-risk failures addressed
- [ ] Human oversight defined
- [ ] Monitoring configured
- [ ] Incident owner identified
- [ ] Rollback/disable mechanism available
