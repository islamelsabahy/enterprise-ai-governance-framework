# AI Evaluation Standard

Evaluate:

## Quality
- Accuracy
- Relevance
- Completeness
- Groundedness
- Calibration

## Safety
- Privacy
- Prompt injection resistance
- Tool misuse
- Hallucination
- Sensitive-data leakage
- Approval boundary adherence

## Operational
- Latency
- Cost
- Failure handling
- Traceability
