# AI Incident Response

## Examples

- Sensitive data exposure
- Unsafe tool action
- Widespread incorrect output
- Prompt injection success
- Unauthorized access
- Model/provider outage
- Material hallucination affecting decisions

## Flow

```text
Detect
→ Contain
→ Suspend/Limit if needed
→ Investigate
→ Assess Impact
→ Correct
→ Validate
→ Restore
→ Post-Incident Review
```
